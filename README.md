# LeetCode Interview Prep — Pattern-Based Live-Coding Demo

A compact, tested Python toolkit showing how I coach algorithm interview prep: learn a handful of **reusable patterns**, practice talking through them out loud, and drill under a timer.

## What's inside

| Pattern | File | Classic problems it unlocks |
|---|---|---|
| Hash map lookup | `patterns/hashing.py` | Two Sum, Group Anagrams |
| Two pointers | `patterns/two_pointers.py` | Valid Palindrome, Container With Most Water |
| Sliding window | `patterns/sliding_window.py` | Longest Substring Without Repeating Characters |
| Binary search on answer | `patterns/binary_search.py` | Search Rotated Array, Koko Eating Bananas |
| BFS / graph traversal | `patterns/graphs.py` | Number of Islands, shortest path in grid |
| Dynamic programming | `patterns/dp.py` | Climbing Stairs, Coin Change, LIS |

Every solution has a docstring with the **intuition, time and space complexity**, and the edge cases an interviewer will probe.

```bash
python -m pytest -q   # or: python -m unittest
```

## How I'd help you prepare (1 week – 1 month)

1. **Baseline session**: one timed medium problem to see how you think, code and communicate.
2. **Pattern roadmap**: ~6–8 core patterns, 3–5 hand-picked problems each, ordered by your weak spots.
3. **Live mock interviews**: you share your screen and solve aloud; I play interviewer, give hints only when needed, then review complexity, edge cases and code clarity.
4. **The interview script**: clarify → examples → brute force → optimize → code → test. We practice it until it's automatic.
5. **Spaced review**: re-solve missed problems a few days later without notes.
